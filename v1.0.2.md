# Shatomin v1.0.2 Release Notes

## Overview
Shatomin v1.0.2 is a public MVP polish update for the badminton rule chatbot.

This version improves the user-facing disclaimer and prepares the app for a cleaner public release.

## Updates
- Improved the disclaimer wording to make it more natural and easier to understand.
- Clarified that Shatomin is a learning and reference tool.
- Added clearer guidance that official matches should follow tournament rules, the umpire, referee, and latest official regulations.
- Replaced the debug-style API error message with a simpler user-friendly message.
- Kept the bilingual Japanese and English style for children, parents, and coaches.

## Current Features
- Bilingual badminton rule chatbot: Japanese + simple English
- Quick question buttons for Service, Doubles, Let, Fault, In / Out, Scoring, and Advice
- Answer modes: Rule, Kids, Coach, and Parent
- Connected to Amazon Bedrock through API Gateway and AWS Lambda
- Hosted on GitHub Pages

## Disclaimer
Shatomin is for learning and reference only.  
For official matches, please follow the tournament rules, umpire, referee, and latest official regulations.

シャトミンは学習・確認用です。  
公式試合では、大会要項、主審、レフェリー、最新の公式規程に従ってください。
